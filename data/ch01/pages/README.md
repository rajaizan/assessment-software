# Chapter 1 page transcripts

One file per printed book page: `b001.txt` = printed page 1 (PDF page 4).
Transcribed by Claude from the page images; Izan spot-checks against the physical book.

## Marks
| Mark | Meaning |
|---|---|
| `## text` | heading |
| `[FIG] text` | figure caption or figure labels |
| `[BOX title] text` | coloured box (Do you know?, Interesting information, activities...) |
| `[?ue]` | scan cuts off this word; only `ue` is visible. Never guess the rest. |
| `[ar?]` | same, but the END of the word is cut off |
| `[?]` | a whole word (or more) is cut off |
| `UNREADABLE` | text is there but cannot be read |

Not transcribed: QR codes, page footers ("Science 7"), pen marks written by a previous owner.
Questions may only quote text that contains none of the `[?...]` / UNREADABLE marks.
